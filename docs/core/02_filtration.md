# Фильтрация

Модуль хранит последние _N_ кадров и обрабатывает каждый из 20 суставов независимо.

## 1. Предсказание при потере видимости

Если сустав присутствует, но не видим, то вычисляется вектор скорости по двум последним валидным кадрам. Новая позиция предсказывается по инерции с экспоненциальным затуханием скорости. При длительной потере видимости сустав плавно интерполируется к дефолтному положению относительно родителя.

## 2. One Euro Filter

Применяется поосево к координатам каждого сустава. Адаптивно меняет частоту среза в зависимости от скорости точки: при низкой скорости сильно сглаживает нейросетевой джиттер, при высокой скорости минимизирует задержку.
