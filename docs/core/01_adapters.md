# Адаптеры

Первый этап конвейера, изолирующий математическое ядро от специфики конкретных CV-моделей.

## 1. Контракт

Каждый адаптер реализует конвертацию сырого плоского массива во внутреннюю структуру `UnifiedBodyPose`. Переключение активного адаптера происходит динамически при получении события `ClientHandshake`.

## 2. Обязанности адаптера

1. Проверка количества отправленных точек для валидации.
2. Конвертация осей в стандарт **glTF**.
3. Нормализация масштаба для 2D и смешанных моделей. Если модель отдаёт данные без метрического масштаба, то адаптер нормализует координаты относительно базовой анатомической длины торса, чтобы компенсировать разную дистанцию объекта захвата до камеры.
4. Перенос сырых точек в единый формат данных из `UnifiedBodyPose`.
5. Вычисление центральных точек позвоночника и шеи.
