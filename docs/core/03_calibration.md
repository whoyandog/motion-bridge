# Калибровка

Определяет мировое смещение корневой кости с индексом 1 (Hips) с поддержкой фоллбэков для моделей разной полноты:

- Горизонтальное смещение берётся из координат `UnifiedBodyJoint::Hips(x, z)`.
- Высота таза над полом: ищется самая нижняя видимая точка опоры в порядке приоритета:
  1. Пятки и носки, если они `Some` и `visibility > threshold`.
  2. Лодыжки - фоллбэк для 17-точечных моделей.
  3. Колени и константная высота - если ноги не попали в кадр.
- Уровень пола сглаживается во времени, чтобы исключить вертикальные подёргивания скелета при ходьбе: `root_position.y = hips.y - min_support_y`.
